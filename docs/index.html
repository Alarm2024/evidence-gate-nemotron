Evidence Gate — offline replay

Step through a stored run: exploit test before/after, fix diff, and verdict. All data is inlined in this page; it makes no network calls.

Bundled seed replays are labeled seed (hand-written, mocked model) — not Nemotron output.

How to verify

Rerun any bundled replay offline (no API key). Evidence Gate reapplies the stored diff, reruns the exploit test, and recomputes the verdict. If it differs from the JSON, the CLI exits with code 3.

python -m evidence_gate run --replay replays/EV-001.json
